- 2026-10-20: итоговая концепция — ядро идеи А + «Аналитика в момент действия» как плагин в Альфа-Бизнесе с масштабированием до расширения браузера; один `POST /interpret`, один `InsightPanel`
- 2026-10-20: профиль компании собирается автоматически, клиент только подтверждает и правит выведенные признаки; факты банка не редактируются
- 2026-10-20: бэкенд только Python, фронт React + Vite, монолит с изолированными сервисами, взаимодействие только по контрактам из `shared/contracts`
- 2026-10-20: тестовая БД — compose-профиль `test` (сервис `db_test`, pgvector/pg16 на порту 5433, данные в tmpfs), а не `testcontainers[postgres]`: CI уже использует postgres-service GitHub Actions с тем же `TEST_DB_URL`, лишней Python-зависимости и Docker SDK нет, на Windows не нужен доступ к docker socket из Python; `make test` поднимает `db_test` и запускает `uv run --env-file .env pytest`

**Why:** эти решения определяют границы задач и не выводятся из кода.
**How to apply:** любое предложение, нарушающее их (второй язык бэкенда, прямой импорт между сервисами, анкета профиля), отклонять и ссылаться сюда.
