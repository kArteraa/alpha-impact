# Дизайн Alpha Impact

Интерфейс читается как интернет-банк Альфа-Бизнеса, но не копирует бренд. Пользователь — финдиректор или казначей: у него мало времени, и «ИИ-тексту» он по умолчанию не доверяет. Панель за 5 секунд отвечает «что это значит для меня и что делать» и показывает у каждого тезиса, факт это, позиция банка или вывод модели.

## Токены

Единственный источник — `frontend/app-plugin/src/styles/tokens.css`. Его подключают и application (`@alpha-impact/plugin/tokens.css`), и расширение. Стили используют только `var(--…)`.

| Группа | Токены |
|---|---|
| Шрифт | `--font-family` (Inter, затем системные), веса 400 / 500 / 700, шкала `--fs-11…--fs-40`, межстрочные `--lh-16…--lh-48`; основной текст 18/26, вторичный 16/24, подписи 14/20, заголовок страницы 40/48 |
| Акцент | `--accent`, `--accent-hover`, `--accent-active` — только primary-действие |
| Текст | `--text-primary`, `--text-secondary` (только на белом, на `--bg-page` ниже AA), `--text-tertiary` (не для значимого текста), `--text-on-dark` |
| Поверхности | `--bg-page`, `--bg-card`, `--bg-neutral`, `--bg-neutral-strong`, `--bg-dark`, `--border`, `--border-soft` |
| Функциональные | `--info`, `--success`, `--warning` (`#F59300` — та же насыщенность, что у остальных), `--danger`, `--bank` (текст на фиолетовой плашке) и плашки `--bg-info`, `--bg-success`, `--bg-warning`, `--bg-danger`, `--bg-bank`, `--bg-ai` |
| Форма | `--r-pill`, `--r-xl`, `--r-lg`, `--r-md`, `--r-sm`, `--shadow-card` |
| Отступы и размеры | шаг 4: `--s-1…--s-8`; контент на всю ширину экрана без ограничивающего контейнера; высота полей и кнопок `--control-h` 56px, `--control-h-sm` 44px |
| Движение | `--t-fast` 150 мс, `--t-base` 200 мс; `prefers-reduced-motion` обнуляет анимации |

## Принципы

- **Смысл раньше фактов.** Карточка открывается заголовком и блоком «Почему это важно для вас» с чипами признаков компании. «Что произошло» свёрнуто, разворачивается по клику.
- **У каждого тезиса видна природа.** Бейдж перед текстом: «Факт» (нейтральный ■), «Банк» (фиолетовый ◆), «AI» (синий ✦). Цвет продублирован формой, поэтому бейдж читается и без цвета. При наведении — источник, клик ведёт к первоисточнику.
- **Позиция банка — самый заметный блок после заголовка:** фиолетовая плашка с датой отчёта и источником.
- **Один красный на экране** — primary-действие («Отправить», «Новый транш»). Статусы, заголовки и навигация не красные.
- **Молчание — хорошее состояние.** Нейтральная галочка и одна фраза причины, без красного и восклицаний.
- **Без мигания.** Панель появляется через 500 мс после изменения ключевого поля. Старая карточка остаётся до прихода новой, поверх неё идёт тонкая полоса прогресса. Форму панель не блокирует и не сдвигает.
- **Честная ошибка.** «Не успел разобраться с этим действием» и «Попробовать ещё раз», без технических слов.
- **Значимость — три точки**, а не процент и не «high / medium».

## Что сознательно не делали

- Логотип, wordmark и шрифт Alfa Interface Sans банка: продукт назван текстом «Alpha Impact», Inter стоит только в font-stack, без загрузки файлов шрифта.
- `@alfalab/core-components` и другие UI-библиотеки: новых зависимостей нет.
- Анимации дольше 300 мс и анимации при `prefers-reduced-motion`.
- Автоопределение ширины панели. Узкий контейнер (side panel расширения) передаёт `compact`, вёрстка при этом одна.
- Отдельное поле «признаки компании» в контракте. Чипы берутся из `source_ref.title` тезисов с источником `profile` и `graph`; новое поле — задача типа contract.
