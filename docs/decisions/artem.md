# Решения — Артём Калюжный

Личный файл журнала решений. Правила и файлы остальных участников — `docs/DECISIONS.md`.

- 2026-10-20: знак `WhatIfResult.value` (рубли) задан для каждого `kind`: `rate_burden` — изменение процентных расходов по портфелю, сумма × (ставка ожидаемая − текущая) / 100 × мес. / 12, плюс — расходы растут, минус — экономия; `deposit_terms` — доход от фиксации ставки минус доход от помесячного переразмещения, плюс — фиксировать выгоднее, минус — выгоднее переразмещать; `fx_exposure` — изменение рублёвой стоимости валютной суммы, плюс — платёж дорожает, минус — дешевеет; ставки и курсы в формуле — со всеми значащими знаками
- 2026-10-20: профиль (AH-7) отдаёт столбец `CL_TYPE` как признак `cl_type` с исходными значениями csv (`CLIENT`, `CLOSE_CLIENT`, …); каталог продуктов не предлагает ничего при `cl_type = CLOSE_CLIENT`, а также когда признака `cl_type` нет или он пуст (статус клиента неизвестен); имена флагов профиля и тегов выводов для правил продуктов берутся из `backend/apps/services/products/rules.yaml` (раздел `vocabulary`), каталог с именем не из словаря не загружается; AH-7 выдаёт флаги, AH-18 — теги выводов с этими именами
- 2026-10-20: LLM-шлюз (AH-16): allow-list моделей и цены в рублях за 1M входных и выходных токенов — `backend/apps/services/llm/models.yaml`, модель вне него не загружается; эмбеддинги — через `/embeddings` того же API с моделью `MODEL_EMBED`; кэш ответов и дневной расход — в Postgres (`llm_cache`, `llm_usage`), чтобы api и seed делили один бюджет и кэш переживал рестарт; день бюджета — по UTC; тратится `LLM_DAILY_BUDGET_RUB × (1 − LLM_BUDGET_RESERVE_SHARE)`, при исчерпании — `BudgetExceeded`, а кэш отвечает и дальше; деление 60/30 на онлайн и пакет пока не делается; запасной модели для interpret нет
- 2026-10-20: ошибки LLM-шлюза — подклассы `DomainError`: `BudgetExceeded` из контрактов, `ModelUnavailable` (HTTP-ошибка, таймаут, обрыв) и `ModelOutputInvalid` (пустой ответ или не по схеме) в `apps/services/llm/errors.py`; потребители ловят `DomainError` и не зависят от httpx, pydantic и сервиса llm — контракт не меняется; ответ не по схеме учитывается в расходе, но не кэшируется, чтобы повтор мог получить валидный ответ
