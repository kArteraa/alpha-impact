# TEAM — кто за что отвечает и в каком порядке делает

Четыре человека, четыре потока, два общих стоп-дня: конец дня 2 (КТ1 — платёж работает сквозь всё) и конец дня 4 (КТ2 — демо проходит без правок кода). Агент у каждого свой (вписать в таблицу), пайплайн — один (`docs/PIPELINE.md`). Критерии готовности каждой задачи — в `docs/BACKLOG.md`.

| | Роль | Агент | Ревьюит | Что принимает на КТ |
|---|---|---|---|---|
| Участник 1 | Платформа: shared, gateway, llm, инфра, безопасность, сдача | | Участника 2 (и все изменения контрактов) | `docker compose up -d --build` на чистом клоне, CI, деплой |
| Участник 2 | Ядро интерпретации: interpreter, критик, whatif, products, followup, регрессия, e2e | | Участника 1 | карточка по платежу с источниками, молчание, критик |
| Участник 3 | Данные и знания: profile, counterparty, house_view, news, метрики | | Участника 4 | профили, house view с версиями, индекс новостей |
| Участник 4 | Фронт и демо: application, InsightPanel, расширение, живая новость (UI), презентация, Jira | | Участника 3 | сквозной сценарий в UI, демо |

Правило очереди: задача берётся только если все её «Зависит от» в статусе Done или Review; если упёрся — берёшь следующую из своего списка, а блокирующему пишешь в канбан. Контракты меняет только Участник 1 по пайплайну «contract», остальные — через него.

## Участник 1 — Платформа

Отвечает за то, что проект поднимается одной командой, что сервисы не могут нарушить изоляцию, что модели вызываются только через шлюз, и за всё, что сдаётся жюри. Первым делает фундамент, на который встают остальные трое, поэтому день 1 у него самый плотный.
