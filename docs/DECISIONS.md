# DECISIONS — журнал решений команды

Решения, которые не видны из кода и остальных документов. У каждого участника свой файл в `docs/decisions/`: решение дописывается только в свой файл, чтобы параллельные PR не конфликтовали. Этот файл — правила и оглавление, решения в нём не пишутся.

Правила для всех файлов журнала:

- Только дописывать в конец, по строке на решение: `- ГГГГ-ММ-ДД: решение — почему`.
- Старые строки не переписывать: если решение изменилось, добавить новую строку, которая его заменяет (в том числе запись из чужого файла — новой строкой в своём).
- Сверяться со всеми тремя файлами. Предложение, противоречащее записи (второй язык бэкенда, прямой импорт между сервисами, анкета профиля), отклонять со ссылкой на неё.
