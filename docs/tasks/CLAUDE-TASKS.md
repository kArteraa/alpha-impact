# CLAUDE-TASKS — как выполнять задачи в Claude Code

Задачи для всех одни — `docs/tasks/BACKLOG.md`, порядок — `docs/TEAM.md`, пайплайн — `docs/PIPELINE.md`. Этот файл только про то, как тот же пайплайн запускается в Claude Code.

## Подготовка (один раз)

1. Установить ECC по `docs/ECC-SETUP.md` (плагин + `configure-ecc`, профиль core, только скиллы из списка).
2. Убедиться, что `.claude/rules/ecc/` в репозитории заполнена (копируется при бутстрапе).
3. `gh auth login`; при желании — MCP Atlassian для статусов Jira.
4. Открыть репозиторий в Claude Code: `CLAUDE.md` подхватывается сам, скилл `/task` лежит в `.claude/skills/task/`.

## Запуск задачи

```
/task "Выполни задачу AH-7"
```

Скилл находит ключ, читает задачу в `BACKLOG.md`, создаёт ветку, вызывает `/ecc:plan` и останавливается до одобрения. Дальше шаги 2–10 из `docs/PIPELINE.md` с инструментами ECC: `/ecc:tdd-workflow`, `/ecc:refactor-clean`, `/ecc:verification-loop`, `/ecc:code-review`.

## Стоп-точки, на которых агент ждёт человека

- после плана
- перед ручной проверкой (UI, демо, качество текста карточек)
- перед push и PR

## Если что-то не так

- `/ecc:plan` не появляется в plan mode → ECC не установлен или rules не скопированы, см. `docs/ECC-SETUP.md`
- агент предлагает действие вне плана → отвечать «не планировали», это нарушение `CLAUDE.md`
- `make check` падает на чужом коде → не чинить чужое, писать владельцу в канбан
