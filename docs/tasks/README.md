# Задачи

Один бэклог — `BACKLOG.md` (47 ключей Jira `AH-1…AH-47`, 5 эпиков, 41 задача, 1 резерв). Порядок выполнения по людям — `../TEAM.md`. Пайплайн один для всех — `../PIPELINE.md`.

Файлы `CLAUDE-TASKS.md`, `GEMINI-TASKS.md`, `CODEX-TASKS.md` — не разные списки задач, а инструкции, как тот же пайплайн запускается в конкретном агенте. Кто каким агентом пользуется, вписывается в таблицу `../TEAM.md`; задача выполняется одинаково, различаются только команды.

## Формат задачи в BACKLOG.md

```
### AH-<n> · <название>
- Эпик: AH-<e> · День: <1–5> · Тип: feat | fix | refactor | contract | docs | chore · Зависит от: AH-<k>, …
- Ответственный: Участник <1–4>
- Что сделать: 1–4 предложения, без деталей реализации
- Готово, когда: проверяемые условия (тесты, команда, экран)
```

Ключи фиксированы: Jira-задачи создаются скриптом бутстрапа ровно с этими номерами (summary = `AH-<n> · …`), поэтому номера не переиспользовать и не сдвигать. Если задача дробится — подзадачи `AH-<n>.1`.

## Канбан в Jira

Колонки: `To Do → In Progress → Review → Done`. Переход в `Review` — при открытии PR в `dev`; в `Done` — после мержа и зелёного CI. Лейблы: `p0`…`p3`. Компоненты = имена сервисов и `front-application`, `front-plugin`, `shared`, `infra`. Исполнители — по `../TEAM.md`.
