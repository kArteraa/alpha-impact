## Что вводить на показе

Прогрев `scripts.warm_demo` идёт по `backend/data/seed/demo.yaml` и попадает в кэш, только если на показе ввести ровно те же значения (ключ кэша `/interpret` — хэш контекста действия). Кэш `/interpret` живёт `CACHE_TTL_SECONDS` (1 ч): прогрев запускать не раньше чем за час до показа; повтор после — из кэша LLM (7 дней), быстро и за 0 ₽.

| Шаг | Пользователь и компания | Что ввести |
|---|---|---|
| 2 | `user_cfo_wholesale`, `U_1941`, затем `U_9250` | лента главного экрана |
| 3 | `user_cfo_wholesale`, `U_1941`, роль финдиректор | платёж `U_96105` «Северо-Западная логистика», 4 500 000 ₽ |
| 4 | `user_cfo_nocard`, `U_235754` | лента главного экрана |
| 5 | `user_cfo_wholesale`, `U_1941` | депозит 50 000 000 ₽ на 90 и на 180 дней |
| 6 | `user_cfo_wholesale`, `U_1941`, роль казначей | тот же платёж `U_96105`, 4 500 000 ₽; роль меняется на `/role`, после шага вернуть «Финансовый директор»: шаг 7 прогрет от финдиректора, а роль запоминается для пользователя |
| 7 | `user_cfo_wholesale`, `U_1941` | главный экран → «Вставить новость»: ссылка `https://demo.example/cbr-key-rate` и «Текст для шага 7» ниже (заголовок первой строкой), «Разобрать новость»; экран обрезает пробелы и переводы строк по краям текста, поэтому в кэш попадает и текст с переводом строки в конце; без ссылки или с другим текстом ответ пойдёт в модель |

```
docker compose --profile seed run --rm -e LLM_TIMEOUT_SECONDS=30 -e LLM_INTERACTIVE_TIMEOUT_SECONDS=30 seed python -m scripts.warm_demo
```

Скрипт печатает по шагу «карточка/молчание, из кэша/от модели» и расход; код выхода 1, если шаг не совпал с ожиданием.

Текст для шага 7 (тот же, что в `demo.yaml`, без отступов YAML; ссылка — `https://demo.example/cbr-key-rate`):

```
Банк России сохранил ключевую ставку на уровне 14% годовых
Совет директоров Банка России сохранил ключевую ставку на уровне 14% годовых. Регулятор отметил, что инфляция замедляется, но остаётся выше цели, и допустил снижение ставки в начале следующего года. Кредиты для бизнеса остаются дорогими, банки сохраняют высокие ставки по депозитам.
```
