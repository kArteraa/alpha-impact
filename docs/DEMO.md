## Что вводить на показе

Прогрев `scripts.warm_demo` идёт по `backend/data/seed/demo.yaml` и попадает в кэш, только если на показе ввести ровно те же значения (ключ кэша `/interpret` — хэш контекста действия). Кэш `/interpret` живёт `CACHE_TTL_SECONDS` (1 ч): прогрев запускать не раньше чем за час до показа; повтор после — из кэша LLM (7 дней), быстро и за 0 ₽.

| Шаг | Пользователь и компания | Что ввести |
|---|---|---|
| 2 | `user_cfo_wholesale`, `U_1941`, затем `U_9250` | лента главного экрана |
| 3 | `user_cfo_wholesale`, `U_1941`, роль финдиректор | платёж `U_96105` «Северо-Западная логистика», 4 500 000 ₽ |
| 4 | `user_cfo_wholesale`, `U_1941` | «Вставить новость»: текст спортивной новости из `demo.yaml` |
| 5 | `user_cfo_wholesale`, `U_1941` | депозит 50 000 000 ₽ на 90 и на 180 дней |
| 6 | `user_cfo_wholesale`, `U_1941`, роль казначей | тот же платёж `U_96105`, 4 500 000 ₽ |
| 7 | `user_cfo_wholesale`, `U_1941` | «Вставить новость»: текст о ставке ЦБ 14% из `demo.yaml` |

```
cd backend && LLM_TIMEOUT_SECONDS=30 LLM_INTERACTIVE_TIMEOUT_SECONDS=30 uv run --env-file ../.env python -m scripts.warm_demo
```

Скрипт печатает по шагу «карточка/молчание, из кэша/от модели» и расход; код выхода 1, если шаг не совпал с ожиданием.
