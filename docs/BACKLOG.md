```
### AH-<n> · <название>
- Эпик: AH-<e> · День: <1–5> · Тип: feat | fix | refactor | contract | test | docs | chore · Зависит от: AH-<k>, …
```

Номера фиксированы: не переиспользовать и не сдвигать. Новая задача получает следующий свободный номер и встаёт в конец своего эпика.
